# Imágenes normalizadas

Reemplace estos nombres con fotografías optimizadas WebP o AVIF; no cambie sus rutas en `config/site-config.js` salvo que necesite más elementos.

- `logo.webp` y `favicon.webp`
- `hero.webp`, `about.webp`
- `service-01.webp` a `service-04.webp`
- `gallery-01.webp` a `gallery-05.webp`
- `testimonial-01.webp` a `testimonial-03.webp`

Si una imagen aún no existe, la plantilla muestra un fallback visual en vez de un icono de imagen rota. Para la mejor calidad, use 2000 px de ancho para el hero y 1200–1600 px para el resto.
